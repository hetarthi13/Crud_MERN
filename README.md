# MERN Stack CRUD Application with Redux

A full-stack web application built using the MERN stack (MongoDB, Express, React, Node.js) and **Redux Toolkit**. This project demonstrates complete CRUD (Create, Read, Update, Delete) operations, where the React frontend uses Redux async thunks to manage state and communicate with a RESTful Node.js/Express backend API.

---

## Features

- **Create:** Add new user data via interactive React forms connected to Redux state.
- **Read:** Fetch and display all user data dynamically from the MongoDB database.
- **Update:** Edit existing user records in real-time with automatic UI updates.
- **Delete:** Remove user entries instantly with database sync.
- **State Management:** Centralized global state using **Redux Toolkit** (`createSlice`, `createAsyncThunk`).

---

## Tech Stack

### Frontend
- **React.js** – UI Component Library
- **Redux Toolkit & React-Redux** – Global State Management & API Thunks
- **Axios** – HTTP Requests
- **CSS / Bootstrap / Tailwind** – Styling

### Backend
- **Node.js** – JavaScript Runtime Environment
- **Express.js** – Web Framework for Node.js
- **MongoDB & Mongoose** – NoSQL Database & ODM Model
- **Cors & dotenv** – Middleware & Environment Variable Management
